FreeBirdWall Installer

Puts FreeBirdWall, free firmware for the FlightWall mini, on your wall over USB. Version …. Everything happens in this page; nothing is sent anywhere.

1Connect the wall

Set the wall up with the FlightWall app first, as usual, so it knows your Wi-Fi. Then plug a USB-C data cable into the port inside the back of the wall and into this computer. Use Chrome or Edge.

2Check the board

The installer only continues on the exact board the firmware was made for, so it cannot harm different hardware.

    3Save a backup

    A copy of everything on the wall (8 MB), saved on this computer, so it can always be put back exactly as it is now. Takes a few minutes; if you already have one from an earlier install, you can skip it.

    4Install

    Writes FreeBirdWall next to the firmware the wall runs now, checks what was written, and only then makes it start next. Your Wi-Fi, account and settings stay.

    5First start

      For later: the update key

      Updates can also be installed over Wi-Fi with the desk tools; they need this file. Keep it private. Plugging in USB and using this page works without it.

      Save flightwall-device.json

      Go back

      Start the vendor firmware again (it stays on the board after an install), or put a backup back.
